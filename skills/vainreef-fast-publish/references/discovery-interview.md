# 需求访谈

先问一句：你想做一个什么样的 App？可以描述画面、玩法、感觉或日常场景。

按用户回答逐层确认（仅聚焦于产品功能与视觉体验，**严禁向用户询问 slug、Electron、代码架构等任何技术黑话**）：

1. 目标用户、使用时机和核心价值；
2. 打开后的第一眼和一次完整操作；
3. 成功结果、空状态、输入错误与保存反馈；
4. 画面风格、排版、颜色偏好；
5. 第一版必须有、明确暂不做的功能；
6. 暂定应用中文名称（英文目录 slug 由 Agent 自动推导，严禁打扰用户）。

确认句：

> 明白了，我会直接把应用做出来并在屏幕上为你打开体验；你可以随时提出调整意见。

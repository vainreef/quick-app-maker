# Partner Center V2 运行契约

唯一入口：

```text
.\bootstrap\qam.cmd store <command> --app <app>
```

## 阶段

| 阶段 | 命令 | 完成标准 |
| --- | --- | --- |
| 名称 | `reserve` | ProductId、Identity、Publisher 回填 |
| 预检 | `preflight` | MSIX、manifest、素材、文案通过 |
| 会话 | `launch` | 独立 Edge 连接，用户已登录 |
| 发现 | `discover` | SubmissionId 和实时路由写入 checkpoint |
| 六表 | `apply --phase` | 冷加载 Diff=0，模块 Complete |
| 总检 | `verify` | Overview 六个模块均 Complete |
| 交付 | 用户操作 | 用户复核后点击提交认证 |

## 收敛判定

`0 differences`、点击成功、当前 DOM 相等和进程退出码 0 都是中间证据。只有以下链路完成才写 `Converged`：

```text
PageKind 已识别
→ 完整 Observed
→ 完整 Diff=0
→ 当前 URL 冷导航
→ 再次 Observed + Diff=0
→ 对应 Overview 模块 Complete
→ 写入 checkpoint
```

## 包状态

同名包只允许一行：

- 没有同名行：上传；
- Processing：等待；
- Validated：跳过；
- Error 或重复：阶段停止，先 repair。

文件名、缩略图、按钮点击和页面停留都不等于 Validated。

## 会话

Edge 使用工作区独立 profile，CDP 只监听 loopback。session JSON 保存 PID、端口、profile、owner 和时间。`stop` 只结束 owner 对应进程。

# Partner Center V2 运行契约

唯一入口：

```text
.\bootstrap\qam.cmd store <command> --app <app>
```

## 账号与签名基础

- **账号与认证**：微软账号与个人开发者认证是免费/极低门槛的；`store launch` 启动 Edge 后，若用户无账号则引导注册，若未认证则引导个人认证；
- **签名由商店接管**：MSIX 包由微软商店云端统一自动完成签名（Store Signing），**完全不需要开发者购买或配置第三方代码签名证书**。

## 流水线标准时序

| 序号 | 阶段 | 命令 | 完成标准 |
| :---: | --- | --- | --- |
| 1 | 会话与保留名称 | `store launch` | 启动独立 Edge，用户登录并亲自在页面输入名称点击保留产品名称 |
| 2 | 名称与 Identity 同步 | `store reserve` | 自动抓取已保留的 ProductId、Identity、Publisher 回填本地清单 |
| 3 | 生产封装 | `package --profile store` | 生成符合 Store 规范的 MSIX 程序包 |
| 4 | 离线静态预检 | `store preflight` | MSIX、manifest、素材、文案预检通过 |
| 5 | 提交发现 | `store discover` | SubmissionId 和实时路由写入 checkpoint |
| 6 | 自动化六表 | `store run --apply` | 自动化填写 6 大阶段，冷加载 Diff=0 |
| 7 | 冷加载总检 | `store verify` | Overview 六个模块均 Complete 绿标 |
| 8 | 最终人工交付 | 用户在 Edge 中复核 | 用户核对无误后亲自点击提交认证 |

## 收敛判定

`0 differences`、点击成功、当前 DOM 相等和进程退出码 0 都是中间证据。只有以下链路完成才写 `Converged`：

```text
PageKind 已识别
→ 完整 Observed
→ 完整 Diff=0
→ 当前 URL 冷导航
→ 再次 Observed + Diff=0
→ 对应 Overview 模块 Complete
→ 写入 checkpoint
```

## 包状态

同名包只允许一行：

- 没有同名行：上传；
- Processing：等待；
- Validated：跳过；
- Error 或重复：阶段停止，先 repair。

文件名、缩略图、按钮点击和页面停留都不等于 Validated。

## 会话

Edge 使用工作区独立 profile，CDP 只监听 loopback。session JSON 保存 PID、端口、profile、owner 和时间。`stop` 只结束 owner 对应进程。
